# Hermes persistent memory

Redacted, daily-synced copy of the Hermes agent memory.

- `sessions/YYYY-MM-DD.jsonl` — every session message for that UTC day (one JSON per line)
- `updates/YYYY-MM-DD.md` — daily session summary table
- `files/` — MEMORY.md, USER.md, SOUL.md (secrets redacted)
- `backups/YYYY-MM-DD/manifest.json` — sha256 manifest of this folder (last 30 days kept)

Coverage: 2026-09-27 to 2026-10-14, 2722 messages. Regenerated by `scripts/hermes_memory_sync.py`.
